# 因子测试

行情窗口右上角的下拉框选「因子测试」。这一页直接读 `data/nasdaq100` 里的日线，不读 `outdata`，也不改指数增强已经写好的 JSON。已经打开的窗口要关掉再开，下拉框里才会出现这一项。

页面有两栏：因子测试、策略回测。计算在后台线程里跑，界面只调用 `services.factor_lab_service`。

## 行情从哪来

股票池里的代码对应 `data/nasdaq100/{代码}.csv`，名单可以按「填入纳斯达克100」从 `data_fetch/nasdaq100_constituents.txt` 填入。指数文件 `NDX.csv` 只作基准，不放进股票池。

复权口径：`adj_factor = Adj Close / Close`，用它去乘开、高、低、收。成交量保持原始值。当前这批文件里 `Adj Close` 与 `Close` 相同，所以因子实际用的是未复权价格。某一天收盘涨跌绝对值超过 50% 时，只在提示里记一笔疑似拆股，不把这一天的因子改成 0。

没有行业分类。勾选行业中性时会提示并跳过。没有市值，回测里选市值加权时会提示并改成等权。

## 因子测试页在算什么

先按股票算出因子原始值，再按交易日做去极值和截面标准化。IC 和 RankIC 是当天因子值对未来若干日收益的横截面相关，当天至少要有 3 只股票。分组在每月最后一个交易日切分，第一天切成几组，后面就固定用这个组数；切不出来的月份跳过。柱状图是各组未来收益的年化，净值是持有到下个月的等权收益连乘。换手是相邻两期成员变化的单向比例。单调性是组号和组平均收益的 Spearman 相关。相关矩阵把各因子按日期和股票叠在一起再算 Pearson 和 Spearman，绝对值达到 0.7 的配对会写在摘要里。

## 策略回测页在算什么

方向选「自动」时，用 RankIC 均值的符号决定做多高分还是做多低分。调仓可以是每日、每周或每月。成交可以按信号日收盘价，或下一交易日开盘价。先卖后买。单票权重有上限，剩下的留成现金。佣金、滑点和卖出税从现金里扣。买不起一手时少买；当天没有价格就保留原股份，等下一次有价格再调。绩效里的换手按成交金额计算，胜率和盈亏比按先买先卖的回合计算。基准默认是本地 `NDX.csv`，也可以改成股票池等权。

这一套成交在 `backtest/execution.py` 的 `run_backtest`。指数增强那条优化路径仍是 `backtest/portfolio.py` 的 `simulate`，两边互不影响。

## 增加一个因子

在 `factors/price_volume.py` 写一个函数，签名是 `(frame, window) -> Series`，索引与 `frame` 对齐。窗口不够、除数为 0 或相关系数方差为 0 时返回 NaN，不要填充，也不要在这里做去极值、标准化或方向翻转。名字带 `_N` 的因子使用界面上的窗口；不带 `_N` 的组合因子可以忽略这个窗口。

然后登记两处：

```python
FACTOR_HELP["新因子"] = "一句话说明"
FACTOR_REGISTRY["新因子"] = 新函数
```

界面启动时会从注册表列出因子，不用改窗口代码。

## 增加一条回测规则

成交规则放在 `backtest/execution.py` 的 `run_backtest`。新参数放进 `config`，由 `services/factor_lab_service.py` 的 `run_strategy` 从界面配置传进去。界面文件不要读 CSV，也不要把公式写进 `gui/`。
