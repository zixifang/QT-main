# 开发说明

界面只展示 `outdata` 里已经算好的 JSON。算法程序单独读取 `data`，再把结果写进 `outdata`。两边不要绕过这个边界。

## 目录

| 路径 | 谁写入 | 谁读取 |
|---|---|---|
| `data/` | 人工放入原始行情 | 算法程序 |
| `outdata/<数据集>/` | 算法程序 | 界面 `python -m gui` |
| `algorithms/` | 各算法的独立程序 | 命令行运行 |
| `engine/` | 回测计算 | 算法程序调用 |
| `gui/` | 展示 | 只读 `outdata` |

## 美股日线下载

`python -m data_fetch.tech_us` 用 yfinance 下载约 40 只科技美股近 10 年的前复权日线。每只股票写成 `data/tech-us-10y/{代码}.csv`，成功的股票再合并成 `data/tech-us-10y/tech_us_10y.csv`。股票列表、起止日期和保存目录在 `data_fetch/tech_us.py` 顶部。Block 使用现行代码 XYZ。上市不满约 10 年的股票会记下并继续。

`python -m data_fetch.manufacturing_us` 同样下载 46 只美国制造业美股，写到 `data/manufacturing-us-10y/{代码}.csv`，合并文件是 `manufacturing_us_10y.csv`。列表和日期在 `data_fetch/manufacturing_us.py` 顶部。分拆较晚的公司（如 GEV）历史可能不足 10 年，会记下并继续。

`python -m data_fetch.nasdaq100` 下载纳斯达克100指数和成分股，起始日 `2015-01-01`。当前行情源是新浪美股日线（`PRICE_SOURCE = "sina"`）。列与其他 CSV 相同：`Date,Open,High,Low,Close,Adj Close,Volume`。新浪给出的是未复权成交价，没有单独的调整收盘价，因此 `Adj Close` 与 `Close` 相同。指数写到 `data/nasdaq100/NDX.csv`，成分股写到同目录的 `{代码}.csv`，合并长表是 `nasdaq100.csv`。未完成的代码写在 `checkpoint.txt`，失败代码写在 `failed.txt`，质量报告是 `quality.csv`。已有且非空的 CSV 会跳过；`--force` 全部重抓。名单默认读 `data_fetch/nasdaq100_constituents.txt`。指数拉取失败时用 `QQQ` 的收盘价代理，并在日志里标明。`PRICE_SOURCE` 还可改为 `eastmoney` 或 `yfinance`；Yahoo 可能限流，东方财富在连续请求时可能断开。

## 现在这条链路

1. 原始行情放在 `data/` 的子目录里。当前有 `data/Equity-Portfolio-Management-master/*.csv`、`data/tech-us-10y/{代码}.csv`、`data/manufacturing-us-10y/{代码}.csv` 和 `data/nasdaq100/{代码}.csv`。
2. 生成 RSI 结果：

```powershell
python -m algorithms.rsi
```

3. 每个有单只股票 CSV 的目录都会写出一套 JSON。2018 样本在 `outdata/equity-2018/`，科技美股在 `outdata/tech-us-10y/`，美国制造业在 `outdata/manufacturing-us-10y/`。`data/nasdaq100` 整目录跳过，由指数增强单独计算。带 `Ticker` 列的合并文件（如 `tech_us_10y.csv`、`nasdaq100.csv`）不单独计算。空目录会跳过。
4. 打开界面：

```powershell
python -m gui
```

左侧上方选择数据集，其下选择模式：行情演示或实盘模拟。中间是股票表（代码、整体涨跌、价格），下方是算法结果集。行情演示就是原来的行情页。右上角仍可进入指数增强和因子测试；实盘模拟时这两项停用。纳斯达克100的股票表第一行是纳斯达克指数，不计入成分股。选中指数时，右侧只有两页：指数行情，以及所选组合相对纳斯达克指数的净值和指标。选中成分股时仍是原来的五页。换数据集就重填这张股票表。按年或按月时，整体涨跌和年末价格跟随选中的年份，换年就重填。按10年时年份选择变灰，整体涨跌是最近10年的涨跌，价格是期末收盘价。右侧五页是原始价格与成交量、买卖点与指标、净值与当年统计表、数据集全局统计、历史走势。前三页图表上方可以选择年份和月份，右侧下拉框在「按月展示」「按年展示」和「按10年展示」之间切换。按年画出该年，按月画出该月，按10年画出最近10年，不随年份选择改变。折线图的图例横排在图上方。单股统计表跟选中年份走，从已保存净值切出这一年。实盘模拟不重算这笔账，只读 `outdata/<dataset_id>/paper/<algorithm_id>.json`。没有这份文件时，右侧提示先运行 `python -m algorithms.paper_account`。

实盘模拟是一个共用账户：本金 100000 美元，只买整股，手续费每成交 1 股 0.005 美元。持仓沿用研究回测已经写好的 `position`，在持仓生效日按前一交易日收盘价先卖后买。当天权重加总超过 1 时缩放到 1，现金不够时买单同比例缩小。有指数时，基准是用这 10 万美元买入指数并持有；没有指数时，基准是第一天等权整股买入全部成分并持有。第 3 页上图是账户美元净值，不缩放到 1。选中哪只股票，账户曲线相同，买卖点和持股数不同。第 4、5 页读这份文件里的 `years`。

第四页读取 `index.json` 里该算法的 `years[<选中年份>]`。`python -m algorithms.rsi` 按自然年把全局统计写进这个字段：每一年有各股策略累计收益，以及策略和买入持有的汇总。综合胜率按该年交易次数加权，综合盈利率是该年各股累计收益的等权平均，收益中位数是这组收益的中位数。指数增强有三行。策略行的综合盈利率、年化、夏普和回撤是组合净值，与指数页同一条日收益；收益中位数和盈利占比是各股策略净值。纳斯达克指数行只有指数这一条净值，股票数、盈利占比和收益中位数留空。持有行是各股买入持有：综合盈利率和收益中位数是等权平均和中位数，平均年化按当年交易日把这个平均收益折成全年，平均夏普和平均回撤是各股自己的平均数。上市不满一年的股票不单独按很短的样本年化后再平均。综合胜率按交易次数，手续费算进去；跑赢只统计当年真正持有过、并且策略收益高于该股买入持有的股票。界面只按选中的年份取出这份结果来画，不在点击时重算。换年就换一份已保存的统计。某年没有写入时，页面提示重新运行 RSI。第五页历史走势按「按整体展示」「按年展示」或「按月展示」截取已经保存的日度净值，窗口内从 0 画累计涨跌。没有日度净值时，整体和按年仍画各年综合盈利率，按月会提示重新运行算法。没有持有序列时不画持有。

## 纳斯达克100指数增强

`python -m algorithms.index_enhance` 读取 `data/nasdaq100`，把结果写到 `outdata/nasdaq100/`。界面里的数据集名称是「纳斯达克100」。成分股名单是 `data_fetch/nasdaq100_constituents.txt`。`NDX.csv` 写成 `NDX.json`，股票表第一行可以查看纳斯达克指数；指数不进入成分股名单。选中指数时，右侧只画指数行情，以及所选组合相对指数的净值和指标。

每月最后一个交易日用当天及以前的数据打分，权重第二天生效。只保留得分最高的 40%，组内按 z 分倾斜，入选的都保留正权重，再归一化到和为 1。落选的股票权重为 0。当天没有行情的股票权重为 0，其余股票重新归一化。组合在两次调仓之间不改股份数量，涨出来的钱留在原来的股票里，下次调仓才用当时的总资产按新权重买回。手续费只在权重变动当天按变动的绝对值收取 0.001。

权重从 0 变成大于 0 的当天是买入，从大于 0 回到 0 的当天是卖出。一直持有、只调整权重时不另记买卖点。

没有调仓日的历史成分名单，所以这些结果不能称为指数增强。股票池是 2026 年 10 月的幸存者名单，并且去掉了 GOOG，只留 GOOGL，避免同一家公司买两次。

算法显示名是 `【指数增强+动量】`、`【指数增强+反转】`、`【指数增强+低波动】`、`【指数增强+流动性】`、`【指数增强+动量低波】`、`【指数增强+等权组合】`、`【高波动对照】`：

- 动量：过去 252 个交易日收益，去掉最近 21 日。按信号日收盘价成交。窗口和 40% 持仓没有用 2021 年以后的行情调整，对外比较看 2021 年以来的资金比和贝塔
- 反转：过去 21 个交易日收益取负
- 低波动：过去 60 日收益率标准差取负
- 流动性：过去 20 日平均成交额
- 动量低波：动量与低波动的横截面排名等权相加
- 等权组合：反转、低波动、流动性取反、20 日收盘价与成交量相关系数，四项横截面排名各占 25%。这一项偏向低成交额，单边成本 0.002
- 高波动对照：下影线、20 日波动、全日振幅的横截面排名各占三分之一。20 日波动用已经把单日涨跌超过 50% 记为 0 的收益。三条合成一条，在下一交易日开盘价成交

指数页的资金比是策略期末资金除以同一段可交易日期上的指数期末资金。贝塔是这段日收益对指数日收益的斜率。不再用两段累计收益相减当作超额。

单股 JSON 的净值按这只股票自己的现金账户记账，不乘组合里的小权重。纳入时按前一日收盘价把账户里的现金全部换成股份，因此持有的每一天都计当天涨跌；调出时按前一日收盘价卖出，调出当天不再计涨跌，现金留在这只股票里。下次再纳入时用这笔现金买入，赚到的差价会买到更多股。进出场各收一次手续费 0.001。空仓期间净值不动。买入持有和左侧整体涨跌使用 `return_index`：单日涨跌绝对值超过 50% 时，该日收益记 0，原始收盘价不改。这样拆股和坏点不会变成累计收益。收益、波动、夏普和回撤都按这条净值的日收益计算。交易记在卖出的那年，赢亏比的是卖出后的现金和买入前的现金，手续费算进去；跨年还没卖出的不在年末结案。股票数是当年有行情的全部成分股，七个算法用同一份名单。盈利占比是这些股票里当年策略收益为正的比例，分母就是股票数。综合胜率是当年已卖出的交易里现金增加的比例，分母是交易次数，和跑赢不是同一个数。综合盈利率、收益中位数、平均年化、平均夏普、平均回撤都是这批股票各自净值当年涨跌的平均或中位数；没持有的日子收益记 0，年化按当年交易日数折算。跑赢只计当年持有过、且净值涨幅高于该股买入持有的股票，没买过的股票不算跑赢。买入持有一行用同一批股票的自身行情，不交易，所以交易次数为 0、综合胜率和跑赢留空。分年 `symbols` 的累计收益就是这条净值在当年的涨跌。第四页柱状图和综合盈利率用的是同一组数。

## F-Score 季度多头

`python -m algorithms.fscore_long_short` 读取 `data/nasdaq100` 的未复权日线和 `data/factors/factors_nq100.parquet` 里的九个 0/1 分项，把结果写到 `outdata/nasdaq-xbrl`。界面数据集名称是「纳斯达克XBRL」。行情在各股 JSON 和 `NDX.json`，算法名是 `【F-Score】`。

`algorithms/fscore_long_short.py` 也可以直接接收行情表和基本面表，只返回调仓、日收益和绩效。

调仓日是 1、4、7、10 月的第 10 个交易日，当月交易日不足 10 天则跳过。`merge_asof` 在调仓日只取 `filing_date` 不晚于当天的最新财报。九项里缺失超过两项就剔除，否则按有效项的通过比例放大到 9 分。`delta_leverage` 用杠杆变化，下降才记 1；九项如果已经是 0/1，调用时加 `already_flags=True`。过去 20 个交易日的平均成交额（收盘价乘成交量）不超过 100 万美元的股票不参与。只买入得分最高的约 10%，等权持有，分数卡在分位上的股票全部留下，离开这个区间就卖出。权重不为负。下一交易日按开盘价成交，也可以改成 VWAP。旧仓只计前收盘到成交价，新仓只计成交价到收盘。绩效从第一次实际成交那天起算年化收益、夏普和最大回撤；行情里若有 `SPX`、`^GSPC`、`GSPC` 或 `SPY`，会把它当成标普 500，不放进股票池。

## 增加一个数据集

在 `data/` 放好原始文件，写一个独立程序，按 `docs/AGENT开发须知.md` 的 JSON 结构输出到 `outdata/<新的数据集id>/`。界面会自动列出带 `index.json` 的子目录，不需要把数据集名字写死在界面里。

## 增加一个算法

不要把计算公式放进 `gui/`。新建 `algorithms/<算法名>.py`，读取 `data`，把同一结构的结果合并进对应股票 JSON 的 `algorithms` 字段，并在 `index.json` 的 `algorithms` 数组里登记。全局统计按自然年写在该算法条目的 `years` 里，键是四位年份。界面上的数据集、股票表和全局统计只反映 JSON 里已经存在的内容。换数据集时，算法列表只显示该数据集股票 JSON 里已经写入结果的算法。
