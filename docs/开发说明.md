# 开发说明

界面只展示 `outdata` 里已经算好的 JSON。算法程序单独读取 `data`，再把结果写进 `outdata`。两边不要绕过这个边界。

## 目录

| 路径 | 谁写入 | 谁读取 |
|---|---|---|
| `data/` | 人工放入原始行情 | 算法程序 |
| `outdata/<数据集>/` | 算法程序 | 界面 `python -m gui` |
| `algorithms/` | 各算法的独立程序 | 命令行运行 |
| `engine/` | 回测计算 | 算法程序调用 |
| `gui/` | 展示 | 只读 `outdata` |

## 美股日线下载

`python -m data_fetch.tech_us` 用 yfinance 下载约 40 只科技美股近 10 年的前复权日线。每只股票写成 `data/{代码}.csv`，成功的股票再合并成 `data/tech_us_10y.csv`。股票列表、起止日期和保存目录在 `data_fetch/tech_us.py` 顶部。Block 使用现行代码 XYZ。上市不满约 10 年的股票会记下并继续。

## 现在这条链路

1. 原始行情在 `data/Equity-Portfolio-Management-master/*.csv`。
2. 生成 RSI 结果：

```powershell
python -m algorithms.rsi
```

3. 结果写到 `outdata/equity-2018/`：`index.json` 加上每只股票一个 `{代码}.json`。
4. 打开界面：

```powershell
python -m gui
```

左侧上方选择数据集，中间是股票表（代码、全年涨跌、年末价格），下方选择算法。换数据集就重填这张股票表。右侧三页仍然是原始价格与成交量、买卖点与指标、净值与统计表。

## 增加一个数据集

在 `data/` 放好原始文件，写一个独立程序，按 `docs/AGENT开发须知.md` 的 JSON 结构输出到 `outdata/<新的数据集id>/`。界面会自动列出带 `index.json` 的子目录，不需要把数据集名字写死在界面里。

## 增加一个算法

不要把计算公式放进 `gui/`。新建 `algorithms/<算法名>.py`，读取 `data`，把同一结构的结果合并进对应股票 JSON 的 `algorithms` 字段，并在 `index.json` 的 `algorithms` 数组里登记。界面上的数据集、股票表和算法列表只反映 JSON 里已经存在的内容。
